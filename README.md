# P Vaishnavi — Product Portfolio

This is a lightweight static portfolio created for internship applications, including the Paytm Product Design Intern application.

## Files
- `index.html` — portfolio content
- `style.css` — responsive styling
- `script.js` — small interaction helper

## Deploy on GitHub Pages
1. Create a new public GitHub repository named `portfolio` (or `Vaishnavi72-6.github.io`).
2. Upload `index.html`, `style.css`, and `script.js`.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will provide your public portfolio URL.
